## 0.3.0

- `KeychainRepository.store(keyId, material)` keeps 32 bytes of key material
  made outside the device — a data key generated by a cloud key management
  service, for example — protected exactly like a key `create` made, and
  `read` gives the same bytes back. It shares `create`'s name space and rule:
  a key already stored under the id is kept and
  `KeychainKeyAlreadyExistsException` is thrown, so replacing a key is
  `delete`, then `store`.
- **BREAKING**: `KeychainInvalidKeyMaterialException` joins the sealed
  `KeychainException` family, thrown by `store` for material that is not 32
  bytes, before the platform is touched. An exhaustive `switch` over the
  family needs a case for it.
- `KeychainKeyEntity.materialByteCount` (32) names the size every key has.
- Native: a new `store` channel method on both platforms. An app that pairs
  this Dart side with an older native build gets
  `KeychainPlatformFailureException`, never a randomly generated key in place
  of the one it handed over.

## 0.2.0

**BREAKING**: `KeychainRepository.isAvailable` is now a getter. It takes no
arguments and answers a yes-or-no question, so it reads as a property.
Migrate by dropping the parentheses:

```dart
// before
if (await keychain.isAvailable()) { … }

// after
if (await keychain.isAvailable) { … }
```

The platform channel method is still called `isAvailable`, so the native side
is unchanged.

## 0.1.0

First release.

- `KeychainRepository` — `create`, `generate`, `read`, `exists`, `delete`,
  `isAvailable` and `availabilityChanges` over 256-bit keys kept by the iOS
  Keychain and the Android Keystore. `KeychainRepository()` builds one backed
  by the platform; the implementation is not exported.
- `KeychainKeyEntity` — a key id and its 32 bytes of material; `toString`
  never prints the bytes.
- `KeychainException` — a sealed family with fixed messages and an optional
  numeric `diagnosticCode`. No logging dependency.
- Native plugin classes for iOS and Android, registered through
  `GeneratedPluginRegistrant`, with identifiers under `net.kaiwu.keychain`.
